# Booking System

Kichik xizmat ko'rsatuvchi biznes uchun appointment booking API (Django + DRF + PostgreSQL).

## Ishga tushirish

```bash
cp .env.example .env
docker compose up --build
```

- Health check: http://localhost:8000/api/health/
- API docs (Swagger): http://localhost:8000/api/docs/

> README keyingi bosqichlarda arxitektura, edge case'lar va AI'dan foydalanish bo'limlari bilan to'ldiriladi.
